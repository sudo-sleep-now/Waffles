## Other ways to install

- **Wally** — see the [installation guide](/guide/installation).
- **Build from source** — clone the repo and build with Rojo:
  ```sh
  git clone https://github.com/sudo-sleep-now/Waffles.git
  rojo build default.project.json -o Waffles.rbxlx
  ```
- **All versions** — browse every release at [github.com/sudo-sleep-now/Waffles/releases](https://github.com/sudo-sleep-now/Waffles/releases).
